# pixel-for-lofi — 雪の夜の窓

窓から、雪の降る夜の街をながめるピクセルアートアニメーションです。
スマホの画面いっぱい（同じ縦横比）に表示されます。PC で開くと、スマホと同じ比率（9:19.5）の枠の中に表示されます。

## 見どころ
- しんしんと降る雪（奥・中・手前の3層、風や突風でゆらぐ）
- 窓の外の桟に少しずつ積もる雪、ガラスにくっついて消える雪の粒、窓の隅の霜
- 向かいの建物の窓明かりがときどき点いたり消えたりする、テレビのちらつき
- 街灯、ネオン看板、アンテナの赤いランプ、煙突の煙、月と星、流れる雲
- ときどき通る車（ヘッドライト付き）と、傘をさして歩く人
- 一点透視で描いた奥行きのある部屋：厚みのある壁にはめこまれた窓、奥行きのある窓台、遠近法で並ぶ床板とラグ、左右の壁と天井
- 窓台の黒猫（耳がぴくっと動き、しっぽがゆれる）、湯気の立つマグカップ、ろうそくの灯り、本、ガーランドライト
- 手前のサイドテーブルで回るレコードプレーヤー

## 使いかた
- 画面をタップすると設定が出ます
  - **雪**: しんしん / ふつう / ふぶき
  - **環境音**: 風の音とレコードのパチパチ音（コードで合成した音）
  - **全画面**
- 対応ブラウザでは、表示中に画面が消えないようにします（Wake Lock）
- 「ホーム画面に追加」するとアプリのように全画面で開けます。オフラインでも動きます

## 動かしかた
ビルドは不要です。静的ファイルをそのまま配信するだけで動きます。

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で
このブランチのルート（`/`）を公開元に選んでください。

## ファイル
| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面と設定 UI |
| `app.js` | 絵の生成とアニメーション（画像素材は使わず、すべてコードで描画） |
| `manifest.webmanifest`, `sw.js`, `icons/` | ホーム画面追加・オフライン用 |

絵は横 約160ドットの小さなキャンバスに描き、端末の画素に合わせて整数倍で拡大しているので、どの画面でもドットがくっきり表示されます。
